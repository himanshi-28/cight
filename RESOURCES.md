# Java and Spring Boot Backend Engineering Resources

## Knowledge

- [Java Language Basics — dev.java](https://dev.java/learn/language-basics/)
  Oracle's maintained learning material for Java syntax and language behavior. Use for Core Java questions encountered in CIght.
- [Java 21 API Documentation](https://docs.oracle.com/en/java/javase/21/docs/api/)
  Authoritative Java SE API contracts. Use before relying on memory about collections, time, concurrency, streams, or standard exceptions.
- [Spring Framework Core Technologies](https://docs.spring.io/spring-framework/reference/core.html)
  Official reference for dependency injection, beans, validation, resources, and the application context. Use for Spring lifecycle and container questions.
- [Spring MVC](https://docs.spring.io/spring-framework/reference/web/webmvc.html)
  Official request-processing, controller, validation, exception, and testing reference. Use for API-boundary tickets.
- [Spring Transaction Management](https://docs.spring.io/spring-framework/reference/data-access/transaction.html)
  Official transaction abstraction and declarative transaction reference. Use for persistence and outbox boundaries.
- [Spring Data JPA](https://docs.spring.io/spring-data/jpa/reference/)
  Official repository, query, projection, pagination, locking, and auditing reference. Use for JPA tickets.
- [Spring Boot Testing](https://docs.spring.io/spring-boot/how-to/testing.html)
  Official guidance for unit, slice, integration, and full-context tests. Use when choosing the smallest useful test scope.
- [PostgreSQL Documentation](https://www.postgresql.org/docs/current/)
  Authoritative SQL, transaction, index, aggregate, and query-plan behavior. Use for schema and performance decisions.
- [Docker Get Started](https://docs.docker.com/get-started/)
  Official image, container, Compose, storage, and networking concepts. Use before Docker tickets and debugging.
- [Apache Kafka Design](https://kafka.apache.org/documentation/#design)
  Official design documentation for delivery, ordering, replication, and consumer behavior. Use for distributed-system tickets.
- [GitHub Actions Documentation](https://docs.github.com/en/actions)
  Official workflow, event, runner, artifact, secret, and deployment documentation. Use for CI/CD tickets.
- [Spring Security OAuth2 Resource Server JWT](https://docs.spring.io/spring-security/reference/servlet/oauth2/resource-server/jwt.html)
  Official JWT validation behavior. Use for issuer, audience, expiry, and authorization work.
- [Spring AI Retrieval Augmented Generation](https://docs.spring.io/spring-ai/reference/api/retrieval-augmented-generation.html)
  Official modular RAG and advisor APIs. Use for retrieval-flow design and implementation.
- [Spring AI PGvector](https://docs.spring.io/spring-ai/reference/api/vectordbs/pgvector.html)
  Official PGvector integration, configuration, filtering, and schema guidance. Use for vector storage and search.
- [Spring AI Google GenAI Embeddings](https://docs.spring.io/spring-ai/reference/api/embeddings/google-genai-embeddings-text.html)
  Official Google embedding configuration. Use for model, dimension, and task-type choices.
- [Spring AI Tool Calling](https://docs.spring.io/spring-ai/reference/api/tools.html)
  Official tool registration and execution model. Use for bounded agent tools.
- [Model Context Protocol Specification](https://modelcontextprotocol.io/specification/)
  Authoritative MCP protocol and lifecycle reference. Use for MCP boundaries and interoperability.
- [Spring AI MCP](https://docs.spring.io/spring-ai/reference/api/mcp/mcp-overview.html)
  Official Spring MCP client and server integration. Use for local CIght MCP tickets.
- [Google SRE Book](https://sre.google/sre-book/table-of-contents/)
  Google's freely available reliability text. Use for availability, observability, capacity, and failure-mode discussions.

## Wisdom (Communities)

- [Spring Questions](https://spring.io/questions)
  Spring's official guidance for seeking community help. Use after consulting documentation and preparing a minimal reproducible example.
- [PostgreSQL Community](https://www.postgresql.org/community/)
  Official directory of PostgreSQL community channels. Use for database behavior and operational questions that need practitioner input.
