Backend glossary

Short definitions that CIght lessons will use consistently.

API contract

The externally observable agreement between an API and its consumers: route, method, inputs, outputs, status codes, and semantics.

Aggregate query

A database query that reduces many rows into a smaller result, such as a count, average, minimum, maximum, or grouped summary.

Derived query

A Spring Data repository query generated from a method name such as countByStatus.

JPQL

Java Persistence Query Language. It queries mapped entities and their fields rather than PostgreSQL table and column names directly.

Metric semantics

The precise meaning of a metric, including which records qualify, which time window applies, and how edge cases are treated.
